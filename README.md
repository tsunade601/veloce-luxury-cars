# VÉLOCÉ — Luxury Automotive

> *Performance, refined.*

A bespoke luxury automotive digital experience built with Next.js (App Router), TypeScript, Tailwind CSS, Framer Motion, and Lenis smooth scrolling.

## Overview
VÉLOCÉ represents the pinnacle of performance engineering and minimalist luxury design. This web platform delivers a cinematic, editorial campaign experience designed for high-net-worth automotive connoisseurs.

## Tech Stack
- **Framework**: Next.js 14+ (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Smooth Scroll**: Lenis Scroll
- **Icons**: Lucide React / SVG bespoke icons

## Routes
- `/` — Cinematic brand home, flagship vehicle showcase, engineering philosophy, and gallery
- `/models` — Full model portfolio with performance metrics and specifications
- `/models/[slug]` — Deep-dive vehicle experience with dynamic 360/color selector, tech breakdown, and bespoke configuration
- `/about` — Heritage, design ethos, engineering excellence, and brand timeline
- `/contact` — VIP concierge test-drive reservation & private showroom appointments
